# Lista de Tarefas

Aplicação de lista de tarefas feita com HTML, CSS e JavaScript puro, sem bibliotecas.

🔗 **Demo:** https://vpavaneli.github.io/lista-de-tarefas/

## Funcionalidades

- Adicionar, concluir e remover tarefas
- Filtros: todas, pendentes e concluídas
- Modo claro e escuro
- Tarefas e tema salvos no navegador (`localStorage`)
- Layout responsivo

## Tecnologias

- HTML5
- CSS3 (Flexbox e variáveis CSS)
- JavaScript (manipulação do DOM e `localStorage`)

## Como rodar localmente

1. Clone o repositório:
```
   git clone https://github.com/vpavaneli/lista-de-tarefas.git
```
2. Abra o arquivo `index.html` no navegador.

usar HTML, CSS e JavaScript para criar arquivos que formam uma pagina interativa, e principalmente criar respositorios, salvar e subir no GitHub
